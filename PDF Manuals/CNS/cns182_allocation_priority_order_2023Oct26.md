[[CNS]] PRIORITIES 
[[CNS]] Priorities is the order in which [[CNS]] allocates positions in a security to Long Members. This is governed 
by an algorithm which changes daily as to not benefit any one [[Member]] over another. The algorithm which 
governs the allocation of long positions is based on priority groups in descending order, age of position within a 
priority group and random numbers within age groups. They include the following:  
A Long positions in a Reorg sub-account (G and/ or H) on an offer with a greater than 2 day protect where 
allocations can occur until actual end of guarantee delivery period. 
Long positions that were instructed by a [[Member]] to be moved to a Reorg sub-account (G and/or H) prior to 
the night cycle of [[CNS]] end date of the voluntary offer. 
Note: There cannot be a [[CNS]] voluntary corporate action and a Buy-in going on at the same time in [[CNS]] for 
a security. 
B Long positions against which Buy-In Notices are due to expire that day but which were not filled the previous 
day (Day 2 Buy-Ins). 
C Long positions against which Buy-In Notices are due to expire the following day (Day 1 Buy-Ins). 
D Long positions in a receiving [[ID]] Net Subscriber’s agency account established at [[DTC]]. 
E Long positions against the component [[securities]] of index receipt agents. 
F Long positions in a [[Member]]’s account who has a High Priority instruction. 
G Long positions in a [[Member]]’s account who has a Low Priority instruction (or no priority instruction).

When more than one long position in each security exists within the same priority group, the following applies 
in only the day cycle: 
• The oldest position is allocated first. Age is defined as the number of consecutive days during which the 
position has been long, irrespective of quantity.  
• All of which have been long for the same number of consecutive days, the allocation rank is 
determined by a computer-generated random number. Random numbers, which change daily, are 
computed so that each [[Member]]'s random number is different for each security.  
[[Member]] Instructions (Applicable to F and G in the Table) 
The allocation algorithm for night and day delivery cycles is computed separately for [[Member]] instructions. 
Each [[Member]] who is not an index receipt agent will have a Standing Priority Instruction for both sub-account A 
(General Account) and sub-account E (Fully Paid-For Account) on the [[NSCC]] Masterfile. The [[Member]] informs 
[[NSCC]] of this instruction at the time they activate their account. This standing instruction can be updated by the 
[[Member]] at any time by submitting a request change with [[NSCC]] Account Administration. A [[Member]] should 
work with their Relationship Manager if they decide to make a change. 
The standing instructions available are as follows: 
High-High (6464) [[Member]] wants high priority to receive [[shares]] in the night cycle and high priority to 
receive [[shares]] in the day cycle. 
High-Low (6468) [[Member]] wants high priority to receive [[shares]] in the night cycle and low priority to 
receive [[shares]] in the day cycle. 
Low-Low (6868) [[Member]] wants low priority to receive [[shares]] in the night cycle and low priority to 
receive [[shares]] in the day cycle. 
 
For each [[settlement]] date, [[CNS]] will use these standing instructions unless a [[Member]] submits a Priority 
Override instruction for a given security(s) by 6:30 PM EST on the business day before [[settlement]]. Each 
Priority Override changes the [[Member]]'s relative rank in the allocation algorithm for its long position in that 
security only. The Priority Override remains in effect for one day.  
A [[Member]] can submit a Priority Override Instruction by submitting a file using the record layout for [[CNS]] Priority 
instructions or manually by using the Priority input screens on the [[CNS]] Dashboard. For more information, log 
in to the Learning Center, and then view the [[CNS]] Dashboard User Guide. 
Index Receipt Agents (Applicable to E in the Table) 
An Index Receipt Agent will be given a higher priority for their Standing Instruction on the [[NSCC]] Masterfile 
than other Members. Since Index Receipt Agents [[DO]] not provide override instructions, their Standing Priority 
Instructions will be used for each [[settlement]] date. As per [[NSCC]] rules and outlined in the table above, their 
standing instructions are always higher than the typical [[Member]].
