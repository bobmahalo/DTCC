Overview 5 
1. OVERVIEW 
The CMU RTTM® Web application has been redesigned to improve the user experience and make use of the 
most current technology. The redesign is part of a companywide [[DTCC]] effort to standardize web applications. 
The look and feel of the CMU RTTM Web screens has been refreshed and their functionality enhanced.   
The CMU RTTM Web Quick Reference Guide is a condensed version of the CMU RTTM Web User Guide. 
This guide is designed for users already familiar with CMU RTTM Web and need to become acquainted with 
the new screens, new features, and new enhancements.   
An updated CMU RTTM Web User Guide will be made available before the new CMU RTTM  Web screens go 
into production in late Q3 or early Q4 2018. However, users familiar with CMU RTTM  Web should find this 
Quick Reference Guide sufficient to understand the differences between the previous and updated versions of 
the CMU RTTM Web application. 
New CMU RTTM® Web Features 
New CMU RTTM Web features include: 
• Ability to use Google Chrome (version 58 or higher) in addition to IE 11  
• Improved navigation on all screens 
• Ability to return up to 200 records on a single page and up to 3,000 total records.  
• Ability to set up a [[default]] Column Selector  
• Trade advisories more clearly displayed on screens

Advanced Search – Added Functionality. Appendix A provides a step-by-step guide on how to utilize the 
column selector feature.

perform this function. 
 
Figure 11: Advanced Search - Added Functionality

could be displayed.  
• CMU RTTM Web can now also return up to 3,000 trades from a single search—previously only 1,500 
trades could be returned.

7. APPENDIX A: SETTING UP [[default]] COLUMNS 
Creating and Setting [[default]] Columns Using Column Selector 
The Column Selector provides users with the ability to choose which columns are displayed in their [[default]] 
view. Users may opt to display columns not included in CMU RTTM Web’s [[default]] view, like Trade [[settlement]] 
Designation ([[CNS]] or TFT), [[DTC]] SIT (which provides the type of security – CD, Corp Bond, Convertible Bond, 
etc.), Accrued Interest, [[CUSIP]] Description, and others. 
Access Column Selector 
1. To access the Column Selector and set up a [[default]] Column, users need to access the Trade Search 
Engine. This can be done either via Quick Link or from the Trade Management menu at the top of CMU 
RTTM Web. 
 
Figure 20: Trade Search Engine Links

Select and Move Columns without Using Search 
Users can also select columns they wish to move from the left side (available) to the right side (to be included 
in your Column Set) by scrolling up and down through the columns and clicking them. This method permits 
selecting and moving multiple columns at once. 
1. Drag the left-side scroll bar up or down to find a column you wish to move and include. Click to select it 
and then click the > symbol to move/add the column to the right side where it will be included in your 
Column Set. 
 
Figure 26: Column Selector w/out Search 
2. You can select multiple (and non-adjacent) columns at once and move them. Use the Shift key while 
selecting the columns on the left side and then click any > to move the columns to the right and add them 
to your Column Set.
