INTRODUCTION TO THE EXCHANGE TRADED FUND 
([[ETF]]) WEB PORTAL
[[ETF]] agents  and authorized participants (APs) can use the Exchange Traded Fund Web portal to: 
l Subscribe or unsubscribe to all available [[ETF]] portfolios using the [[ETF]] Portfolio Subscription Inquiry page.
l View and download the portfolio details after subscribing to an [[ETF]] portfolio.
l Access real time portfolio composition information that is pulled from Security Master database.
l Request historical portfolio details. Information about this feature will be provided in a later version.
l Customize alert notifications.
During the Portfolio Distribution Process on T-1 and T, the system distributes the appropriate portfolios to 
each subscriber.  Subscribers are charged a daily fee for each portfolio. 
Setting Up Access to the Exchange Traded Fund ([[ETF]]) Web Portal
Note
The [[ETF]] Web user interface is now available through the Clearing Dashboard,  within the [[DTCC]] portal, 
enabling a standardized user experience and conforming to the user experience center of excellence 
(UXCOE) standards. All existing features remain the same with some improvements to clearly differentiate 
between baskets. Existing roles will continue to work with no action required. You can display only the 
clearing accounts to which you have access per the roles that set up for you by your super access 
coordinator (SAC). For SAC that need access to the Clearing Dashboard, contact Registration Support 
Group at NSCCIntegration@[[DTCC]].com.
Access the Exchange Traded Funds ([[ETF]]) Web account  through the Clearing Dashboard. Your access is 
determined by the permissions established for you by your firm's super access coordinator (SAC), according 
to your firm's policies and procedures. Ensure your  firm's SAC includes access to the Clearing Dashboard 
along with the [[ETF]] Web user interface in your permission set up. 
You can display only the clearing accounts to which you have access. Your SAC sets up roles that govern 
what you can view, access, and modify. If you have only view access, you cannot subscribe or unsubscribe 
to [[ETF]] portfolios or run historical processes. If you have update access, you have access to all of the 
features, such as the ability to auto subscribe and unsubscribe to [[ETF]] portfolios. In addition to view and 
update access, the SAC sets up the features you can view. For example, if you have access to Historical 
Inquiry, you only see the [[ETF]] Historical Portfolio Request tab. Contact the SAC at your firm to obtain or 
update your permission, provide access to the Clearing Dashboard, and set up your [[ETF]] account.

[[ETF]] PORTFOLIO SUBSCRIPTION INQUIRY
[[ETF]] agents and authorized participants (APs) use the [[ETF]] Portfolio Subscription Inquiry page to subscribe 
and unsubscribe to all available portfolios. [[DTCC]] members need to subscribe to a portfolio to view or 
download the details for that subscribed portfolio. You can subscribe to all portfolios  or  select individual 
portfolios as long as your [[ETF]] Tag Account has the necessary access. During the portfolio distribution 
process that occurs on T-1 and T, [[ETF]] distributes the appropriate portfolios to each subscriber.  Subscribers 
are charged a daily fee for each portfolio subscription. 
You can search the last five trade dates to view all available subscriptions permissible from your [[ETF]] Portfolio 
[[ID]]. You have the ability to search for Restricted (formally known as Custom) portfolios assigned to you, not 
those that are assigned to another [[participant]]. For Restricted portfolios, the Exchange Traded Fund ([[ETF]]) 
Web application automatically subscribes users that are authorized by [[ETF]] agents. This subscription is 
available only for one business day.
Access the [[ETF]] Portfolio Subscription Inquiry page daily to view the appropriate portfolio subscription 
information  in the Enhanced Consolidated PCF Output format to each subscriber.
Note
The data retrieved and displayed is associated with your [[ETF]] Tag Account [[ID]] for your firm. To change the [[ETF]] Tag Account, see Elements of the Exchange Traded Fund ([[ETF]]) Web Page.
The following subscription options are available:
Subscription OptionDescription
Auto Subscribe Automatically subscribe to all current standard portfolios  and any new future 
portfolio that are submitted  by all agents.
Subscription by AgentAutomatically subscribe to all current standard portfolios and any new future 
portfolio that may be submitted for a particular agent.
[[BASIC]] SubscriptionSubscribe to individual portfolios that you select from the search results.
Subscribe to ResultsSubscribes you to  all [[ETF]] portfolios in the search results, not just what is visible on 
the current page.

Searching for [[ETF]] Portfolios
You can view and download portfolio details only for subscribed portfolios. The Exchange Traded Funds ([[ETF]]) 
Web provides Portfolio Composition File (PCF) reporting for all supplemental versions of Standard portfolios 
and only the last supplemental version of a Custom portfolio. 
You can subscribe and unsubscribe to individual portfolios or subscribe to all portfolios using auto subscribe. 
Turn  auto subscribe off if you want to subscribe to individual portfolios. See Turning Off Auto Subscribe. 
Note
You must wait 24 hours between subscribing and unsubscribing to a portfolio.
To search for an existing [[ETF]] portfolio subscription:
 1. Login to the Exchange Traded Funds ([[ETF]]) Web page. See Accessing the Exchange Traded Fund ([[ETF]]) 
Web.
 2. From the Exchange Traded Funds ([[ETF]]) Web page, as shown in the following figure, enter the filter 
criteria to [[Locate]] existing [[ETF]] portfolio subscription results. As you type in the field, such as the  [[ETF]] 
Portfolio Identifier, [[ETF]] Trading Symbol, Component Trading Symbol, or Component [[ID]] field, [[ETF]] 
automatically provides the possible results.
