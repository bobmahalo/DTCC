A [[CUSIP]] number is required to deposit a security in the [[custody]] System. ISINS are currently not eligible for [[custody]]
deposits. The [[custody]] Eligibility system allows you to obtain or reserve [[CUSIP]] numbers for [[custody]] eligible issues.
By allowing you to obtain CUSIPs through self-service, the [[custody]] Eligibility system speeds your ability to make depositsquickly and promotes straight-through processing of [[custody]] deposits.
Requesting CUSIPS
The system allows you to request either a [[CUSIP]] that [[DTC]] generates automatically, or a [[CUSIP]] you specify thereby
reserving it. If you specify a [[CUSIP]], the system will cross-check it with the [[DTC]] Masterfile to ensure it does not already exist
and has no restrictions such as global locks or chills in place.
[[Asset]] Types
The [[Asset]] types for which you may request a [[CUSIP]] and the related sub-issue types are the following:
Corporate [[Equity]]
Common [[Stock]]
Preferred StockLimited Partnership
Depository [[shares]]
[[Warrants]]
[[custody]] (non-standard)*
Corporate Debt
Corporate Bond
Certificates of Deposit
Collateralized Mortgage Obligation
Government Security
[[custody]] (non- standard)*
Municipal
Municipal Bond
* Non Standard is used for issues with safekeeping only; does not include [[Asset]] servicing.
Process for Making Requests
Below is a suggested workflow to follow when requesting a [[CUSIP]]:
1. Search for Eligible CUSIPs – use this search to look up fully eligible or [[custody]]-only CUSIPs from the [[DTC]] Masterfiledatabase. It is a good idea to confirm that a [[CUSIP]] for the security you are depositing does not already exist before
making a request.
2. Request a [[CUSIP]] – use this page to request [[custody]] CUSIPs.
3. Search Submitted Requests – use this search to track the progress of requests. Shows all requests submitted from your
firm, and shows when they become eligible.4. [[PBS]] [[custody]] System – use this handy link on the menu bar to access the [[custody]] system where you can make
deposits.
Other Functionality
Upload Requests – Use this page to upload a spreadsheet of requests. This feature is ideal for large numbers of requestssuch as in preparation for conversions.

2. You may enter a [[CUSIP]] that you would like to reserve.
 If you specify the Security [[ID]] you would like [[DTC]] to make eligible, the following rules apply:
The Security [[ID]] cannot already exist on the [[DTC]] Masterfile.The Security [[ID]] must be eligible for a [[custody]] deposit.
The Security [[ID]] must be a [[CUSIP]].
The [[CUSIP]] must contain nine characters. Numbers and letters only.
The number must have a valid check digit.
Positions two, three, and four in the [[CUSIP]] cannot be alphabetical letters.No special characters are allowed.
Lower case letters are okay. They will automatically be converted to upper case.
UNDER REVIEW STATUS
You may specify a [[CUSIP]] number when entering a request. However, if the [[CUSIP]] you request falls under an exception
category, the request will go Under Review. You will receive an email notifying you that the request is Under Review.
After [[DTC]] staff resolves a request under review, the status changes to Resolved and the [[CUSIP]] is eligible. If [[DTC]] staffcannot resolve the request, they cancel and withdraw it. You will receive an email notifying you that the status is either
Resolved or Withdrawn. Also, [[DTC]] staff can update the request with a different [[CUSIP]], and when eligible, you will receive an
email notification.
These conditions will trigger a request to go under review:
[[CUSIP]] is inactiveCUSIP is marked for deletion
[[CUSIP]] is globally locked
[[CUSIP]] is marked for Chill Segregation
Note: This does not occur when a [[CUSIP]] is generated for you by the system.

There are two worksheets within the spreadsheet. On the first, labeled Requester tab, all fields are required with the
exception of the phone extension and additional contact information which are optional.
The number of requests entered on the Requester tab must match the number of requests entered on the Requeststab. For example, if you entered 6 requests, enter 6 as the number of requests.
To avoid errors, insure the [[participant]] [[ID]] number entered on the Requester tab matches the [[participant]] Number you are
currently logged in with.
Completing the Spreadsheet Requests Tab
The Origin Code field defaults to “Other” automatically. No action is needed. This field is used by [[DTC]] to determine the
source of the request.
The Dated date, if required, cannot be more than 30 days in the future.
The Maturity date, if required must be greater than the Dated and Accrual dates.
The Accrual date on the issue, if required, cannot be more than 30 days in the future.
Working With the Spreadsheet
Rename the USA-[[custody]]-[[CUSIP]]-Request Spreadsheet Template.xlsx file so that you will recognize the file name
after it is uploaded to [[custody]] Eligibility. The file format must remain as an Excel *.xlsx file.
The spreadsheet must be in Pending Certificate status before you can attach the certificates. This occurs one to two
minutes after you upload. Click Search to refresh the page and check the latest status.All requests uploaded on a spreadsheet are submitted for eligibility (whether selected or not). For example, if you
select only some of the requests before choosing “Submit for Eligibility,” all requests will be sent even those not selected.
For this reason it is best to insure the spreadsheet is filled out correctly prior to uploading it.
