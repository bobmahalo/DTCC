Public Price Dissemination (PPD) – Overview
PPD Submission
• Rounding, Capping and Scaling are performed on submissions that are posted on the PPD 
website to prevent fingerprinting of trades. 
• Regulators have required specific Time Delays when disseminating PPD submissions to the 
public which DDR applies accordingly.
PPD Reporting
• PPD Status Report contains all the successful PPD submissions received for the reporting date 
plus previous dates pending trades disseminated on report date per [[Asset]] class per jurisdiction.
• The report includes transformed (rounded, capped, scaled) values as well as original values 
submitted.
UPI and PPD
• UPI will be required on PPD submissions after implementation. 
• The scope includes Credit, Rates, FX, and Equities.
• A compliance date for Commodities has yet to be announced and is out of scope.​
• This differs from trade state which requires updates to open positions by compliance date. 
PPD Message
• This message is used to report the pricing information of the trade and lifecycle events publicly.
• The Reporting Party is required to use this message to instruct DDR to disseminate the record 
on DDR's public website. 
• DDR's message template identifies required fields that must be populated. 
Part 43 ([[CFTC]]/[[SEC]]) and 91-507 (Canada) rules require real-time reporting in order to provide 
price transparency in the market.
