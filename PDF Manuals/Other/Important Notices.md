ACCESSING EVENT PROCESSING DETAILS 
There are three ways to access important notices related to event processing (Rename, Credit Event, Re-
Org and Restructuring events). Please see the below for further details: 
1. DerivSERV Client’s Section 
Here the information is a web-integrated version of the RSS Feed. 
This will allow you to access the event tracker sheet, containing information for events. 
 
https://www.[[DTCC]].com/repository-and-[[Derivatives]]-services/[[Derivatives]]-services/trade-information-
warehouse 
 
2. RSS Feed 
Firms would have to subscribe to receive the feeds that contain event processing details and updates 
(important notices). You can subscribe to this feed via outlook, browser, company intranet, etc. This 
would follow a standard RSS feed setup. 
 
http://www.[[DTCC]].com/rss-feeds 
 
Note that this feed is .xml encoded. This means client must complete this step in Internet Explorer (or 
Microsoft Edge), not Google Chrome for example.

3. [[DTCC]] Website 
Firms can access [[DTCC]] website and retrieve event important notice information.

http://www.[[DTCC]].com/rss-feeds/legal/deriv-and-serv/trade-information-warehouse-tiw 
 
Note: Internet Explorer (or Microsoft Edge) must be used for this [[Option]].
