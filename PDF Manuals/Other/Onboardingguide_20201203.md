User Profile 
Each user must have a profile. The profile contains [[BASIC]] information about that user: company, first name, last name, email address, phone number, and 
(optionally) extension. 
Profiles are unique by company and email address. You cannot create more than one profile for the same company and email address.  
Each profile must have at least one login [[ID]]. The login [[ID]] lets the user log in and use the products for which he or she is registered.  
The login [[ID]] for CA ClaimConnect™ needs to be a Web login [[ID]]. 
Procedure 
1. If the Home page is not already displayed, click Home.  
 
 
2. Click Create Profile.  
You will be prompted to enter user profile information: 
Note:  
If a profile already exists for the email address you entered, a 
warning message will be displayed: “A matching profile already 
exists in CRS.” You will not be allowed to create another profile 
with the same email address. Either change the email address 
or click Cancel and search for the existing user profile.  
If the email domain (the characters to the right of the “@”) you 
entered doesn’t match any of your company’s email domains,

Creating a User [[ID]] in CRS (Client Registration System)  7 
7. To provision the user with access to the 
ClaimConnect™ product, click the checkbox beside 
ClaimConnect.  
Next, click the down arrow next to Roles.  
Place a checkmark next to each desired role.  
 
Use the Role Definitions located at the end of this 
document to determine which roles to select for the user. 
If your firm has more than one account set up for the 
ClaimConnect™ product, you will also have to select 
roles for these account(s) in the same manner.  
If your firm is only set up with a single account, it will by 
[[default]] be selected.  
 
To confirm your selection, click Submit. 
 
8. Once you have selected the appropriate roles and accounts, click Confirm in the lower right corner of the product list. 
 
 
9. Click Submit in the lower right corner of the product list window. 
 
The user is now provisioned with access to the ClaimConnect™ product.
