Data are available in three formats:
A focused refresh file (PFF), including underlying fund and current value
information. A PFF file includes the distributor’s entire book of business and is
typically sent on a daily basis.
A full refresh file (PVF) that provides PFF data, as well as information pertaining to
contract parties and service features. It includes the distributor’s entire book of
business, transmitted according to a schedule agreed upon by trading partners.
A new business file (PNF) that provides data in the identical format to the PVF file
but includes only new contract information. It contains information on contracts that
