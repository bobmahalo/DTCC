1. ABOUT THE CONSOLIDATED TRADE SUMMARY INQUIRY TOOL
The purpose of this document is to assist you with understanding the new Consolidated Trade Summary (CTS) web-
based inquiry tool available from the Clearing Dashboard. On June 23, 2017, existing CTS print-image reports will be 
decommissioned and replaced with the Consolidated Trade Summary (CTS) web-based Inquiry tool. This tool 
enables you  to query CTS information for both current and historical trading activities by [[settlement]] date. Use the 
Inquiry tool to review totals sorted by netting types, [[CNS]] versus non-[[CNS]], domestic versus foreign, regular way 
versus when issued, stocks versus [[Bonds]], markets, symbols, and balance orders. Additionally, you can query the 
CTS data to return cash adjustment, trade summary, and balance order records.
Note
The Clearing Dashboard (CLD) is a landing page that hosts several National [[securities]] Clearing Corporation 
([[NSCC]]) web-based products. The Clearing Dashboard (CLD) is available from the [[DTCC]] Web Portal.
Registering the CTS  Inquiry Tool
To use the CTS inquiry tool, ensure your firm's Super Access Coordinator (SAC) has granted you access to the 
following roles:
Role Description
CLD User Allows access to the Clearing Dashboard (CLD) from the [[DTCC]] Web Portal.
CTS Dashboard Inquiry Allows access to the Consolidated Trade Summary (CTS) tool.
Roles
The process your firm's SAC requests access to the Consolidated Trade Summary (CTS) tool depends on whether 
they have access to the [[DTCC]] Web Portal products and the Clearing Dashboard in the production environment.

Accessing the CTS  Inquiry Page
The Inquiry function allows you to search for CTS transactions and apply filters to achieve the desired results. CTS 
stores and returns historical results for up to seven years. There is no back fill of data; therefore, the CTS Inquiry tool 
begins storing data upon implementation. You can use the CTS Inquiry page to access summary results and balance 
orders for your firm.
To use the CTS Inquiry page:
 1. Access the summary results and balance orders.
 2. View the summary results and balance orders. See Viewing the Summary Results and Viewing the Balance 
Orders.
 3. Filter records, export to a file, and view group details. See Filtering, Exporting, and Downloading Records.
Accessing Summary Results and Balance Orders
To access the summary results and balance orders from the CTS Inquiry page:
 1. Select the Inquiry tab to display the CTS Inquiry page, shown in the following figure.
 Figure 2.3  CTS Inquiry Page
 2. In the required [[settlement]] Date Range field, click 
  Calendar to select a single date or a date range.
