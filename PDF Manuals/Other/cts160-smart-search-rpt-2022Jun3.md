About [[NSCC]] CTS SMART/Search Reporting
To access the CTS SMART/Search reports, you need a valid [[participant]] Browser Services ([[PBS]]) login and 
password. To request access to the [[PBS]] system, contact your firm's super access coordinator (SAC) and request 
the XRNS [[Entitlement]]. 
Use the UTC CTS Trade Summary and UTC CTS Balance Order print image reports to supplement the 
Consolidated Trade Summary (CTS) file or dashboard reporting. Access these reports through SMART/Search, a 
report repository offered by [[DTCC]]. SMART/Search  is a web-based tool that enables access to a variety of [[DTCC]] 
reports.
Note
Since the SMART/Search system has a limit of 1500 pages per document, either refine your search request criteria or contact 
[[DTCC]] Client Support to request the report as one document. To contact [[DTCC]] Client Support, call +1 888- 382-2721, and then 
follow the prompt for product support.

 3. From the Clearance & [[settlement]] [[Equity]] Reports section, click either the UTC CTS Balance Order Report or 
UTC CTS Trade Summary Report link.
 4. You can retrieve a report by either the report version, the [[default]], or report date. Select Retrieve by Report 
Version to search for the entire report by date. The report version refers to a time period when CTS produced the 
report. This report is produced multiple times daily and contains trade capture information across all markets.
To access information beyond recent dates, use the Retrieve by Report Date [[Option]], and ensure you include 
the [[Member]] [[ID]] and type a name for the report in the Work Queue Report Name field.
Notes
Before submitting a request to retrieving a confirm archive by either the report version or report date, specify 
details in the Additional Selection Criteria section.
