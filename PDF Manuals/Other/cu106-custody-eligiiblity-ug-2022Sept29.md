INTRODUCTION TO [[custody]] ELIGIBILITY 
[[custody]] Service 
[[DTC]]’s [[custody]] Service enables clients to outsource the safekeeping and processing of physical [[securities]] that 
are not traditionally eligible for the regular depository services. 
For example, clients may deposit [[securities]] such as customer-registered custodial assets, restricted [[shares]], 
and certain [[DTC]]-ineligible [[securities]] such as certificated money market instruments (MMIs), private 
placements, and limited partnerships. 
[[custody]] Eligibility 
A [[CUSIP]] number is required to deposit a security in the [[custody]] System. ISINS are currently not eligible for 
[[custody]] deposits. The [[custody]] Eligibility system allows you to obtain or reserve [[CUSIP]] numbers for [[custody]] 
eligible issues. 
By allowing you to obtain CUSIPs through self-service, the [[custody]] Eligibility system speeds your ability to 
make deposits quickly and promotes straight-through processing of [[custody]] deposits. 
Requesting CUSIPS 
The system allows you to request either a [[CUSIP]] that [[DTC]] generates automatically, or a [[CUSIP]] you specify 
thereby reserving it. If you specify a [[CUSIP]], the system will cross-check it with the [[DTC]] Masterfile to ensure it 
does not already exist and has no restrictions such as global locks or chills in place. 
[[Asset]] Types 
The [[Asset]] types for which you may request a [[CUSIP]] and the related sub-issue types are the following: 
Corporate [[Equity]] 
• Common [[Stock]] 
• Preferred [[Stock]] 
• Limited Partnership 
• Depository [[shares]] 
• [[Warrants]] 
• [[custody]] (non-standard)*

Process for Making Requests 
Below is a suggested workflow to follow when requesting a [[CUSIP]]: 
1. Search for Eligible CUSIPs–use this search to look up fully eligible or [[custody]]-only CUSIPs from the [[DTC]] 
Masterfile database. It is a good idea to confirm that a [[CUSIP]] for the security you are depositing does not 
already exist before making a request. 
2. Request a [[CUSIP]]–use this to request [[custody]] CUSIPs. 
3. Search Submitted Requests–use this search to track the progress of requests. Shows all requests 
submitted from your firm, and shows when they become eligible. 
4. Link to the [[PBS]] [[custody]] System–use this handy link on the menu bar to access the [[custody]] system 
where you can make deposits. 
Other Features 
Upload Requests–Use this page to upload a spreadsheet of requests. This feature is ideal for large numbers of 
requests such as in preparation for conversions.

Understanding the rules behind data entry and request fields can save you time when entering, uploading, and 
searching for requests. 
Security [[ID]] Field 
 
 
To work with the Security [[ID]] field to request a [[CUSIP]], [[DO]] one of the following: 
• You can request [[DTC]] generate a [[CUSIP]] by leaving the Security [[ID]] blank. 
• You may enter a [[CUSIP]] that you would like to reserve. 
 
If you specify the Security [[ID]] you would like [[DTC]] to make eligible, the following rules apply: 
• The Security [[ID]] cannot already exist on the [[DTC]] Masterfile. 
• The Security [[ID]] must be eligible for a [[custody]] deposit. 
• The Security [[ID]] must be a [[CUSIP]]. 
• The [[CUSIP]] must contain nine characters. Numbers and letters only. 
• The number must have a valid check digit. 
• Positions two, three, and four in the [[CUSIP]] cannot be alphabetical letters. 
• No special characters are allowed. 
• Lower case letters are okay. They will automatically be converted to upper case.

Under Review Status 
 
 
You may specify a [[CUSIP]] number when entering a request. However, if the [[CUSIP]] you request falls under an 
exception category, the request will go Under Review. You will receive an email notifying you that the request 
is Under Review.

[[DTC]] staff cannot resolve the request, they cancel and withdraw it. You will receive an email notifying you that 
the status is either Resolved or Withdrawn. Also, [[DTC]] staff can update the request with a different [[CUSIP]], and 
when eligible, you will receive an email notification.

• [[CUSIP]] is inactive 
• [[CUSIP]] is marked for deletion 
• [[CUSIP]] is globally locked 
• [[CUSIP]] is marked for Chill Segregation
