SPECIFICATION REPORT OVERVIEW 
The Mutual Fund Profile Service II – Profile Security database (MFPS II) is accessed from the MyDTCC Portal.  
The Profile Security homepage is divided into two sections: 
1. Prof ile Security  
2. Specification Report 
 
 
In the Specification Report section, the generation of Specification Reports lev erag es  the data within MFPSII to 
provide greater efficiencies including: 
• For Intermediaries: 
o Ability to create customized report templates based on business needs with [[Asset]] Managers in the 
[[intermediary]] Template Profiles section. 
• For [[Asset]] Managers: 
o Ability to create customized report templates based on business needs. 
o The auto-population of Profile Security data point values to Specification Report. 
o A “Supplemental” data point section providing [[Asset]] Managers the ability to perform data entry for 
commonly identified data points in Specification Reports that [[DO]] not reside in Profile Security.  
o Flexibility for [[Asset]] Managers to override a value for a specific Specification Report without impacting 
the data in Profile Security or the Supplemental section. 
o The [[intermediary]] Template Profiles page where [[Asset]] Managers c an set up a specific template to 
require specific data as required by an [[intermediary]]. 
o Ability for [[Asset]] Managers to review the Specification Report prior to distributing to the [[intermediary]]. 
o Audit history, which provides an audit trail of updates made to data point attributes within the 
specification report and a record of when a report was generated.

Data Dictionary Tab Overview 
The Data Dictionary tab contains three tabs including: Data Dictionary, Best Practices, and Template 
Mappings. 
1. The Data Dictionary tab includes definitions, input types, expected values, and override eligibility of 
Supplemental Data points. 
2. The Best Practices tab defines Best Practices for the Specification Reporting section of Profile Security 
3. Template Mappings provides the data point within a Specification Report that has been mapped and 
defined as a(n): 
o In Profile Data Point – Data Points currently in the Profile Security User Interface.  
o Supplemental Data Point – These are data points that are not tracked in Profile Security but are 
common across multiple Specification Reports.  
o Blank Data Point – These are data points that are specific to one Specification Report or contains 
public information.  These data points need to be updated manually once the Specification report has 
been generated.

automatically be populated on the specification report

3. In the override value field, enter the new value. 
4. Select the record(s) that need to be overridden from the Select Records table.  This table remains blank 
until a data point value to override is selected  
5. And click Next.  If you receive an error message, you must enter a valid value to continue.
