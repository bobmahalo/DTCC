TRANSACTION DESCRIPTION CODE LIST 
Introduction 
This topic provides information on the transaction description codes. 
Purpose  
This table lists the acceptable alpha codes used by a Fund to identify an activity which took place and affected 
a shareholder's position at the Fund. These codes are used in lieu of certain transaction codes on the 
Networking Activity record and represent sub-categories of those transactions.  
The table below describes the transaction description codes.
