About SMART/Track for Buy-ins Primary Home Page 
SMART/Track for Buy-ins is a Web-based system that allows the automation, 
communication, warehousing, and tracking of [[CNS]] and non-[[CNS]] (for example, 
[[NYSE]], AMEX, [[NASD]], [[NSCC]], and [[OTC]]) buy-in notices, as well as MSRB close-out 
notices. 
 
The primary SMART/Track for Buy-ins Home Page acts as a portal to the [[CNS]], non- 
[[CNS]], and MSRB home pages. This primary home page features links to several view 
functions, plus a search function that includes active and archived options. 
 
Click any of the [[CNS]], non-[[CNS]], and MSRB home pages to create notices and to view 
their respective notices and liabilities. Click any of the view functions to open a list 
page from which you can display detail pages. Use the following links to navigate

About SMART/Track for Buy-ins [[CNS]] Home Page 
The SMART/Track for Buy-ins [[CNS]] Home Page contains links that allow you to 
navigate to create and list pages with one click. From the list page, you can select a 
detail page for further action. You can create [[CNS]] buy-in notices one at a time or up 
to 15 at once. You can also view active [[CNS]] buy-in notices and liabilities from list 
pages that are accessed from view functions. This home page includes a search 
function for notices and liabilities. 
 
From the SMART/Track for Buy-ins [[CNS]] Home Page you can quickly and easily 
navigate to pages where you can [[DO]] the following: 
• Create [[CNS]] buy-in notices of intent 
• Create multiple [[CNS]] buy-in notices of intent 
• Create [[CNS]] buy-in orders 
• Create multiple [[CNS]] buy-in orders 
• Create [[CNS]] buy-in executions that generate liability notices to 
the short [[participant]] 
• Create [[CNS]] buy-in retransmittals for buy-ins originating outside 
of [[CNS]] 
• Update or cancel buy-in notices of intent and orders until the 
status changes to Sent 
• View and print [[CNS]] buy-in notices and liabilities 
• Search for active [[CNS]] buy-in notices and liabilities 
• Search for archived [[CNS]] buy-in execution notices and liabilities 
with up to seven years of history 
• Export [[CNS]] buy-in lists and search results

About SMART/Track Notices and Liabilities 
SMART/Track notices, regardless of type ([[CNS]], non-[[CNS]], or MSRB), are buy- 
in/close-out notices that you create and send to a specified counterparty (the
