OVERVIEW RESOURCES
TradeSuite [[ID]] is the U.S. domestic industry-standard post trade processing service
automating the electronic distribution of trade details between counterparties to facilitate
electronic [[settlement]] and regulatory compliance. It can be used as a standalone service by
both brokers and investment managers, or as a part of the ITP 'No-touch' workflow for U.S.
domestic trades.
To learn more about the combined workflow between CTM and TradeSuite [[ID]], please
visit CTM Workflows - US-Specific Workflows.
To learn more about using the features and functionality of TradeSuite [[ID]], including using
the web-based user interface, please access the resources available under Related
Content.
