6. After setting your search criteria:
l To retrieve a report that is available (typically for the last five days), click Search. View your searched report.
l
To retrieve archived reports:
a. Select Retrieve by Report Date.
b. Select the date range using the Date From and Date To fields.
c. From the Additional Selection Criteria section, enter or search for your [[Member]] [[ID]] in the [[Member]]
From field.
d. In the Work Queue Report Name field, type a unique name to identify the work queue report. Ensure
that the name helps easily identify the criteria and details in the report when viewing multiple work
queue requests. This field is mandatory when retrieving a report by the report date. If this required field
is empty and required, an error message appears.
e. Select Add to Work Queue.
