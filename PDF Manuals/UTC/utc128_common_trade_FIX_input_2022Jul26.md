View the header, data details, and trailer information for the UTC Common Trade FIX Input format. To identify which

Notes
l All A/N fields are initialized to spaces ( ). Fields populated with spaces are not transmitted.
l All numeric fields are initialized to zero (0).
l For rejected transactions, some fields with defined values may be populated with a space ( ).
l Fields that are not required on input are not validated. Values submitted in these fields, including special
characters, are passed on output, without modification.
