TRANSCRIPT OVERVIEW 
What follows is a transcript of the eLearning course that explains how to use the Dashboard of the 
[[Underwriting]] Central (UWC) application as it was released in Q2 of 2021. The text below the slide images 
represents the information and navigation instructions included in the Notes panel of the eLearning player. This 
text and the annotations on the slides themselves should be taken together for education purposes. The slide 
numbers shown correlate to the slide numbers appearing in the course outline. These are included to help 
mitigate any confusion which may result from referencing page numbers in this transcript. We encourage you 
to review this and other learning resources about [[Underwriting]] Central available on the Learning Center and to 
complete the “[[Underwriting]] Central: Using the UWC Dashboard” online survey to provide us with your 
feedback.

1.3 Dashboard Introduction 7 
1.3 DASHBOARD INTRODUCTION 
 
Notes: 
The Dashboard allows you to view your firm’s offerings quickly and easily.  
It also helps you identify items that need your attention.  
Offerings in red are in a draft state and need to be submitted to [[DTC]].  
Hovering your mouse over any checkmark or red exclamation point opens a Tooltip providing additional 
information about the status and possibly a link to learn more.  
An offering only advances when its row is filled with gray check marks.

## Page 18

[[Underwriting]] Central: Using The UWC Dashboard Transcript 
1.14 Data Conflicts Column 18 
1.14 DATA CONFLICTS COLUMN 
 
Notes: 
The Data Conflicts column shows any issue or security data discrepancies with underwriters sharing the same 
[[CUSIP]].  
For example, you will see a red exclamation point if you enter an interest rate of 2% and another [[underwriter]] 
enters an interest rate of 3%.  
Use the “Click to Review” link in the available Tooltip to view and modify data conflicts. All conflicts must be 
resolved prior to the offering’s closing.
