ABOUT THIS MANUAL 
This manual is intended to be a guide and reference manual for using the [[Underwriting]] (UW) SOURCE 
application.  
This manual familiarizes end-users with the UW SOURCE application, and explains the tasks that can be 
performed in [[Underwriting]] offerings, issues, and [[securities]]. It also provides descriptions for the fields in the UW 
SOURCE interface. Each part focuses on a specific area. 
• Offering Activity Processing - Part 1 
• Offering Activity Processing - Part 2 
• Dashboards, Work Plans and Work Items, and User Hierarchy - Part 3 
• Queries and Reports - Part 4 
• Eligibility Processing - Part 5

This manual is for the users of UW SOURCE application, such as The [[Depository Trust Company]] ([[DTC]]) staff, 
underwriters, correspondents, transfer agents, [[issuer]], and counsel of [[issuer]], who need to perform various 
tasks to process deals at [[DTC]] using UW SOURCE.

Getting Started 10 
1. GETTING STARTED 
[[DTC]] provides [[custody]] and [[Asset]] servicing for more than two million [[securities]] from the US and 100 other 
countries for its participants and their customers. The [[Underwriting]] Service is the starting point for all security 
offerings at [[DTC]]. Through the service's  New Issue Eligibility program, underwriters can distribute both primary 
and [[Secondary Offerings]] of [[securities]] quickly and economically through electronic book -entry delivery and 
[[settlement]]. These newly issued [[securities]] are then available for the full range of depository services. 
UW SOURCE is a new platform, replacing the legacy [[Underwriting]] systems at [[DTC]]. The integrated platform 
facilitates the streamlining of the [[Underwriting]] process to generate further efficiencies, reduce costs and provide 
greater flexibility. UW SOURCE improves the [[Underwriting]] processing in the following functional areas: 
• [[Underwriting]] Offering Activity Processing 
• Eligibility Processing (Including the Quality Assurance Processing) 
• Security Eligibility Determination

Table 1: COMMON ACTIONS IN UW SOURCE  
Action Name Purpose

Cancel Navigates user back to previous page 
Save Saves the details entered in the pages  
Submit Saves the information entered into UW SOURCE after necessary validations 
Search Displays the results of the entered search criteria 
Go Opens a new page with the list of search results 
Print Enables you to print search results or other tabular data

same across the user interface in UW SOURCE. 
The list of common tasks and its purpose is described in Table 3. 
Table 2: COMMON TASKS IN UW SOURCE  
Action Name Purpose 
Modify Modifies the details of the selected record 
Delete Deletes the selected record  
View Displays the details of the selected record  
Add Adds the details entered for the record to the list 
Open Query Accesses the personalized queries  
Save Query Saves the search criteria as a query for future use

3. SEARCHING FOR DEAL INFORMATION 
Before capturing deal information, as a best practice, you need to search UW SOURCE and determine if any 
information pertaining to the deal already exists in the database. This is important as it can avoid adding the 
same deal information again in UW SOURCE. This chapter explains how to search for [[DTC]] Offering Activity in 
UW SOURCE. 
Note: The composite of all information pertaining to a particular offering is referred to as a “deal” within [[DTC]]. 
An [[Underwriting]] [[DTC]] Offering Activity is a distinct set of deal-related information received in UW SOURCE.  
UW SOURCE enables you to search for saved [[Underwriting]] [[DTC]] offering activity. You can specify any of the 
following search criteria: 
• [[DTC]] Offering Activity List Related Search Criteria 
• Offering List Related Search Criteria 
• Issue List Related Search Criteria 
• Security List Related Search Criteria 
• Security [[underwriter]] List Related Search Criteria

Related Search Criteria

[[DTC]] Offering Activity need to be reviewed before being taken up for further processing when the underwriters 
perform the following actions:  
• Postpone Offering 
• Postpone Issue 
• Reactivate Issue 
• Withdraw Offering 
• Withdraw Issue 
• Withdraw Security 
• Delete Offering 
• Delete Issue 
• Delete Security 
• Delete [[underwriter]] 
• Delete Interest Feature 
• Modify Offering one day before the Expected Closing Date when Issue is Approved 
• Modify Offering when Security is Global Locked or D.O chilled 
• Create/ Modify Secondary Offering (Distribution Type: Secondary) when the Security of Primary Offering is 
not [[settlement]] Eligible 
• When Principal Amortization Type is changed such that it impacts the existing features in a Security (Ex. 
When Principal Amortization Type is changed to ‘Principal Only’ and if an Interest Feature is already 
existing and that needs to be deleted because of this change) 
• When Credit Enhancement is changed from ‘Yes’ to ‘No’ or ‘Not Specified’ (Credit Enhancement Details 
needs to be deleted due to this change) 
• When Zero Coupon Flag is modified to ‘Yes’ and Interest Features are already present then it would 
require deletion of interest feature 
• When Putable Flag is modified from ‘Yes’ to ‘No’, then this would require deletion of Put Feature (if 
available) 
• When Callable Flag is modified from ‘Yes’ to ‘No’, then this would require deletion of Call Feature (if 
present) 
• When Convertible Flag is modified from ‘Yes’ to ‘No’, then this would require deletion of Conversion 
Feature (if present)

GLOSSARY 
Clearing Firm  
An organization that provides specialized comparison, clearance, and [[settlement]] services for its customers. 
Correspondent [[underwriter]] 
An [[underwriter]] that utilizes the services of a clearing firm to settle the transaction through [[DTC]]. The 
correspondent [[underwriter]] is not a [[Member]] of [[DTC]]. 
Deal  
A deal refers to the combination of an offering, its related issues, individual [[securities]], and its associated 
underwriters. It is the basis for all of [[DTC]]’s [[Underwriting]] processes. 
Depository Trust & Clearing Corporation  
[[DTC]] is a subsidiary of the Depository Trust & Clearing Corporation ([[DTCC]]). It handles the [[settlement]] of trades 
in corporate and municipal [[securities]] provides [[custody]] and [[Asset]] servicing for more than two million [[securities]] 
issues from the United States and 100 other countries and territories. 
Dissemination [[underwriter]] 
The Lead or managing [[underwriter]] with responsibility to submit new issue information for dissemination. The 
dissemination agent will generally be the Lead Manager; however, in cases where there are joint lead 
managers, the managers must decide which firm will submit to [[DTC]] for regulatory purposes. 
Final Offering Document 
The final version of an offering document issued for corporations or municipalities. It contains the complete and 
final information about the offering. 
Issue 
Stocks or [[Bonds]] sold by a corporation, municipality, or government entity. 
[[issuer]]  
A legal entity that develops and sells [[securities]] to finance its operations.

Glossary 242 
Offering  
An offering is when a corporation, municipality or government entity elects to bring a new issue to the market in 
order to raise capital. 
Offering Activity  
An Offering Activity is the information about an Offering that is received from underwriters, and [[DTC]]. 
Offering Documents 
A formal written offer to sell [[securities]] that sets forth the plan for the proposed business enterprise (or the facts 
concerning an existing one) that an [[investor]] needs in order to make an informed investment decision. 
[[participant]] [[underwriter]]  
A registered [[Member]] eligible for services at [[DTC]]. 
Paying Agent  
An entity, usually a bank or trust company, that is responsible for transmitting payments of interest and 
principal from an [[issuer]] to the security holder. 
[[SEC]]-registered company 
An offering of [[securities]] that is filed with the [[Securities and Exchange Commission]] ([[SEC]]). 
[[Securities and Exchange Commission]] ([[SEC]])  
A government commission that regulates the [[securities]] markets and protects investors.  
Security 
A security is a unit of an issue. 
[[syndicate]]  
A group of investment banks assembled by a lead manager to underwrite a new issue. 
[[transfer agent]]  
A financial institution that maintains records of investors, cancels, and issues certificates, and deals with other 
related problems.

Glossary 243 
UW SOURCE  
The [[Underwriting]] system. 
[[underwriter]] 
An [[intermediary]] between an [[issuer]] of a security and the investing public. An [[underwriter]] can either be [[DTC]] 
[[participant]] or Correspondent who would clear the [[Underwriting]] deal using the Crediting [[participant]]. 
[[Underwriting]]  
[[Underwriting]] is the process by which new issues are introduced to the [[securities]] industry. 
Uniform Security Identification Procedures ([[CUSIP]]) 
The identification number created by the American Banking Associations Committee on Uniform Security 
Identification Procedures ([[CUSIP]]) to uniquely identify issuers and issues of [[securities]] and financial 
instruments. The [[CUSIP]] number consists of nine digits; the first six digits identify the [[issuer]] and have been 
assigned to issuers in alphabetic sequence, and the next two characters (alphabetic or numeric) identify the 
issue. The ninth digit is the check digit.
